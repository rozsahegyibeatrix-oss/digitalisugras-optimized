## Changes by phase

**0. Audit** — `SEO_AUDIT.md`.

**1. Visible without JS** — Puppeteer post-build prerender (`scripts/prerender.mjs`,
in `npm run build`); the only new dependency (`puppeteer`, dev-only), chosen
because the stack is a plain Vite SPA with no SSR framework. Routes: `/` and
`/home` (unchanged one-pager), `/munkaink`, `/arak`, `/gyik`, plus English
mirrors `/en`, `/en/home`, `/en/work`, `/en/pricing`, `/en/faq`. HU is the default.

**2. Metadata** — `src/lib/seo.js` (single route/copy config), `useSEO` hook:
unique title/description, self-canonical (aliases canonicalize to `/`, `/en`),
hreflang hu/en/x-default, Open Graph, Twitter cards, `og:locale`. OG images
(1200x630 JPG, 49-70 KB) are screenshots of the real rendered pages, produced
by the prerender script per page type and language.

**3. Structured data** — one `@graph` per page, all from real site content:
Organization, WebSite, Service (launch package + 3 tiers), FAQPage (the 5 real
FAQs, both languages), CreativeWork (4 real client sites), BreadcrumbList.

**4. Crawler access** — `robots.txt` allowing all 12 named AI/search bots,
build-generated `sitemap.xml` (8 canonical URLs, lastmod, hreflang alternates),
`llms.txt`.

**5. Headings / images / links** — exactly one h1 per page, no skipped levels
(fixed a stray h1 inside a mockup and an h3-before-h2); alt text in the page
language; aria-labels on the 4 videos; footer link row to every standalone page
and to the other language; language toggle now also updates the URL.

**6. Web vitals** — nothing to change on fonts (system fonts, no third-party
origins, LCP is text). Caching headers in `vercel.json`.

**7. HTTPS / redirects / mobile** — HTTPS + HSTS (max-age 63072000) confirmed live;
security headers, one trailing-slash convention, www to apex redirect,
`404.html` with noindex. Mobile measured in the DOM at 360/390/414/768/1024:
zero horizontal overflow on all routes; every tap target has an effective hit
area of at least 44x44 (invisible `::before`, no visual change); lead-form
inputs 16px on mobile to stop iOS focus zoom.

**8. Human-only** — `SEO_TODO.md` (Search Console/Bing steps),
`BACKLINK_STRATEGY.md`.

## Deviations, stated plainly

- Vercel issues 308 (permanent) redirects, not 301; equivalent for search engines.
- Text below 16px (mono labels, captions, `text-sm` body) left as is: changing
  the type scale restyles the whole site. Decision in `SEO_TODO.md`.
- Video `poster` not added: no real poster frame exists and re-encoding media is
  out of scope.
- FAQPage has 5 questions, not 8-12: only the 5 real ones exist; I did not
  invent more.
- `sameAs`, phone, address: not in the repo, not invented.
- Prerender snapshots the DOM after `useEffect` sets head tags; tags are in the
  shipped static HTML (verified by reading `dist/` files), but they are
  generated by client code at build time, not by a server renderer.
- Deployed and verified live on 2026-09-19 after one fix: the first Vercel build failed on headless Chrome and now uses `@sparticuz/chromium` there (see `SEO_TODO.md` item 1). Lighthouse numbers above were taken before deploy; re-run on the live site.
